# Mini Apps JS

## Descripción
Proyecto con tres mini aplicaciones hechas con HTML, CSS y JavaScript.

## Páginas

### Productos
Filtrado de productos por categoría, precio, stock y búsqueda dinámica.

### App
Lista de tareas con:
-agregar tareas
-marcar como completadas
-eliminar tareas
-contador de pendientes

### API Demo
Consumo de la API de Rick and Morty:
-carga de personajes
-búsqueda dinámica
-manejo de errores
-estado de carga
## Tecnologías
-HTML5
-CSS3
-JavaScript ES6+
-Fetch API
## Cómo usar
1. Abrir el proyecto
2. Usar Live Server
3. Navegar entre las páginas
